# BELENTANI — Archivo completo de la conversación

Este paquete conserva el material generado y utilizado durante la construcción de BELENTANI: código fuente, documentación editorial y técnica, recursos visuales disponibles, historial de versiones Git y una transcripción del contenido conversacional disponible en la sesión.

## Estructura

| Ruta | Contenido |
|---|---|
| `project/` | Código y documentación del proyecto BELENTANI, sin `node_modules`, `dist` ni logs de sesión. |
| `assets/` | Recursos visuales generados y referencias visuales autorizadas disponibles en el entorno. |
| `versions/` | Bundle Git completo y listado de commits identificables. |
| `metadata/` | Procedencia, hashes e inventarios del archivo. |
| `CHAT_TRANSCRIPT.md` | Transcripción editorial del intercambio disponible en esta sesión. |

## Privacidad y límites

El repositorio y la carpeta de Drive deben permanecer privados. No se incluyen credenciales, tokens, configuración privada de conectores, logs internos, `node_modules`, `dist` ni el contenido confidencial de instrucciones del sistema. El historial de Git contiene el código y los commits del proyecto; los checkpoints de la plataforma se registran por identificador y descripción en `versions/commits.txt` cuando son identificables, pero no se exporta ningún contenido interno de la plataforma que no esté presente en el entorno local.

La obra JUDAS continúa protegida: este archivo no incluye audio, master, letra, waveform, descarga ni URL pública del material sellado.

## Procedencia

Los recursos `belentani-*` fueron generados para la dirección visual de BELENTANI. Los archivos `pedro-rizado-perfil-01.jpg` y `pedro-rizado-perfil-02.jpg` son las referencias visuales autorizadas desde Google Drive que se conservaron en la experiencia. La fotografía descartada no forma parte del archivo activo ni del código de la interfaz.
